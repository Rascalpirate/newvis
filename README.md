# NewVis
这个项目的目的：
1. 作为所有项目的root，提供包含路径、.out路径支持；
2. 跟踪3rdparty lib信息，包括源码信息，需要修改的内容，额外的文件结构和cmake；
3. 跟踪部署脚本。

git submodule add git@github.com:Rascalpirate/cctz.git  vis_3rdparty/cctz/src
git submodule add git@github.com:Rascalpirate/spdlog.git vis_3rdparty/spdlog/src
git submodule add git@github.com:Rascalpirate/zpp_bits.git vis_3rdparty/zpp_bits/src

git submodule add git@github.com:Rascalpirate/vis.git
